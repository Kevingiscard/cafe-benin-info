# UMAMI Chill & Grill — QR Menu

MVP mobile-first de menu digital et commande à table.

## Parcours
QR Code → menu → sélection de table → panier → commande WhatsApp.

## URL GitHub Pages
https://kevingiscard.github.io/cafe-benin-info/umami/

## Données
Le contenu public actuellement identifiable mentionne notamment les grillades au feu de charbon et les frites d’igname. Les prix exacts et le catalogue complet doivent être importés depuis le menu officiel avant mise en production.

## Évolution SaaS
La V2 peut remplacer WhatsApp par une API de commandes avec authentification restaurant, PostgreSQL/Supabase, gestion des produits, tables, statuts, statistiques et multi-restaurants.
