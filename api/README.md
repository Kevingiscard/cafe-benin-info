# API hors frontend

Le site public actuel reste un frontend statique compatible GitHub Pages. Il ne contient aucun jeton, aucune clé privée et aucun `fetch` applicatif.

`openapi.yaml` décrit le contrat préparatoire d’un futur backend : santé, observations agrégées et contributions professionnelles modérées. Avant activation, il faudra choisir un hébergeur serveur, une base, une politique de conservation, un anti-spam côté serveur, une limitation de débit, une authentification administrateur, une journalisation minimisée et une politique RGPD complète.

Ne pas remplacer `example.invalid` par une URL publique tant que le service n’est pas réellement déployé et sécurisé.
